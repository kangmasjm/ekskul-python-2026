# 🐍 Ekstrakurikuler Pemrograman Python Club

Selamat datang di repositori resmi ekstrakurikuler Python!

## 📁 Struktur Folder Pengumpulan
Harap kumpulkan tugas di dalam folder dengan format: `NamaSiswa`
Contoh: `Jiem/bio_generator.py`

## ⚠️ Aturan Penting (Wajib Ditaati)
1. **DILARANG** mengedit atau menghapus folder milik teman lain.
2. Selalu lakukan `git pull origin main` sebelum melakukan `git push`.
3. Gunakan pesan commit yang jelas, contoh: `git commit -m "Submit Minggu 1 - Budi"`
